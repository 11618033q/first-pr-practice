# first-pr-practice

A tiny math utilities library, used to practice the GitHub pull request workflow.

## Usage

```python
from mathutils import add, subtract, multiply, divide

add(2, 3)       # 5
subtract(5, 2)  # 3
multiply(4, 3)  # 12
divide(10, 2)   # 5.0
```

## Runing Tests

```bash
python -m unittest discover tests
```
